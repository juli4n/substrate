Actor

Actor is a running or suspended instance of an ActorTemplate: the unit Substrate schedules onto a Worker, checkpoints to a snapshot, and resumes.

MethodDescriptionRequestResponse
GetActor

Get an Actor.

 ateapi.GetActorRequest ateapi.Actor
CreateActor

Create a new Actor deriving from a given ActorTemplate.

 ateapi.CreateActorRequest ateapi.Actor
UpdateActor

Update mutable fields on an existing Actor.

 ateapi.UpdateActorRequest ateapi.Actor
SuspendActor

Suspend a given actor to a new snapshot. A running actor is checkpointed on its worker; a paused actor's node-local snapshot is uploaded, narrowed to the template's commit scope where required (Full capture, Data commit).

 ateapi.SuspendActorRequest ateapi.SuspendActorResponse
PauseActor

Pause a given actor and keep its snapshots on node VM.

 ateapi.PauseActorRequest ateapi.PauseActorResponse
ResumeActor

Resume an actor from its latest snapshot.

 ateapi.ResumeActorRequest ateapi.ResumeActorResponse
DeleteActor

Delete an actor. Only suspended actors can be deleted.

 ateapi.DeleteActorRequest ateapi.Actor
ListActors

List Actors.

 ateapi.ListActorsRequest ateapi.ListActorsResponse
